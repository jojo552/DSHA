# EXP-CLAUDE-001：旧 Android 的 Agent 接入边界

- 日期：2026-09-26
- 关联：REQ-CLAUDE-001
- 类型：decision / pitfall
- 标签：Android、Claude、进程生命周期、MCP

原生页面可避开旧 WebView 的脚本能力限制，但不会自动解决 Ubuntu 内 CLI 对旧内核和内存的要求。声明 Android 6 兼容时，应分别说明 APK、无障碍动作、CLI 运行三个层次的验证范围。

无障碍节点动作可在 API 23 工作，坐标手势与截图分别从 API 24、30 开始；工具服务需要能力查询和明确失败前缀。授权不能继续依赖另一个后端的 Web 生命周期，应绑定仍存活的 Claude 请求，逐次确认。

官方 SDK 可能并发请求多个工具授权，UI 必须排队而非覆盖单个请求。连续文字输出需要节流而非不断推迟刷新；输入与 UI 队列都需限制积累。

独立进程监督可在命令结束时保留 stdout 管道；读取不能只等 EOF，维护锁也不能因命令返回退出码就提前释放。必须按出生身份关闭整个进程组并确认退出。

## 手机交互与登录（2026-09-27）

“手机操作”可能指用户操作 Claude，也可能指 Agent 控制手机；本次用户澄清后应以用户在手机上聊天/编程为主，保留已要求保留的可选工具。当前支持范围改为 Android 10+。

提问选择状态与控件分离，恢复草稿时核对授权请求 ID，避免新问题继承旧选择；流式重绘只在文本变化时执行，用户上滑后暂停自动跟随。登录跳转复用官方 BROWSER 契约和既有本机桥，不另写 OAuth 交换器，不解析终端中的任意链接。

本机 AIDL/ADB 为 SDK 提供的 x86_64 程序，ARM64 Termux 无法直接执行；Java 检查复用已核对的 AIDL 等价产物，官方工具链由 CI 补验。本机额外尝试的 Web locale 测试因缺少 `app/build/locked-dsh-runtime` 产物无法运行，它测试 DSH Web locale，不是本轮原生 Claude 字典；后者已随两版构建生成并编译通过。不能把未执行的真机 style 验收记为通过。
