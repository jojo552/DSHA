# 在 Android 10+ 手机上使用 Claude Code

- 目标仓库：jojo552/DSHA；基线：bdb647c。
- 用户授权：在自己的仓库实现 Claude Code，保留 Android 6+，兼容手机操作。
- 新增独立原生聊天入口、安装/登录入口、流式输出、会话恢复、取消和工具授权。
- 复用现有 Ubuntu、受管资产、环境维护锁、设备桥与权限策略，保留 DSH 功能。
- Android 6 / ARM64：提供读屏、文字点击、输入、控件滚动、导航；能力探测明确报告手势与截图限制。
- Claude Code 原生程序的旧内核运行兼容、设备通道与界面真机体验仍需设备验收。
- 用户已确认暂时没有 Android 6/7 设备，本轮先完成代码和自动化验证。
- 用户确认（2026-09-26）：兼容与验收口径收敛到 **Android 10 及以下**（low 兼容版）；不再要求 Android 6/7 真机作为前置。

## 最新需求（2026-09-27，取代前述兼容口径）

- 用户澄清：本人在手机上操作 Claude，重点是聊天和编程的触屏体验。
- 最低 Android 10；low 调整至 API 29，standard 保持 API 30。
- 保留已有手机控制、MCP、无障碍入口，但聊天和编程不要求开启它们。
- 精简按钮、发送与停止分开、点选单选/多选答案、旋转保留草稿、向上阅读时不抢滚动。
- 用户追加：账号登录授权可以自动打开手机浏览器；由官方 CLI 负责授权码和回调。

## 验收

- SDK 适配测试覆盖流式输出、续聊、授权、取消、错误和进程退出。
- 手机 MCP 测试覆盖旧系统能力、参数验证、错误识别和协议发现。
- Java 逻辑测试、可执行的构建/静态检查；无法执行的项如实记录。
